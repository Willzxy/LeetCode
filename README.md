# LeetCode Solutions

Este diretório é utilizado para armazenar as minhas resoluções de exercícios e problemas da plataforma [LeetCode](https://leetcode.com/).

## Sobre

O objetivo principal deste diretório é manter um histórico do meu progresso na resolução de desafios de algoritmos e estruturas de dados. As soluções focam em diferentes níveis de dificuldade (Fácil, Médio e Difícil) e abordam variadas técnicas de otimização de código e complexidade.

## Como navegar

Os arquivos de código fonte dentro deste diretório correspondem aos problemas resolvidos. O nome de cada arquivo ou pasta reflete o nome ou o número do problema original no LeetCode, facilitando a busca e revisão.
